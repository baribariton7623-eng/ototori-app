# 無料で入手できるMusicXML/.mxl 一覧(調査メモ)

調査日: 2026-08-31

## 前提・注意事項

- この一覧は、大規模オラトリオ・合唱曲について「PDFではなくMusicXML(.xml/.mxl、または.mscz)が実際に無料で入手できるか」を調べた結果のうち、**ファイル単位のURLまで確認できたものだけ**を掲載している。ページ単位でしか確認できていない(=個別ファイルの実在は未検証)ものは掲載していない。
- 調査はWebSearchのスニペット・タイトル情報に基づく。この作業環境のネットワークプロキシがcpdl.org / imslp.org / musescore.com / mutopiaproject.orgへの直接WebFetchをブロックしているため、**リンク先を開いての目視確認はできていない**。実際にパイプラインへ取り込む前に必ず自分でページを開いて中身(声部構成・小節数・ライセンス表記)を確認すること。
- 原曲がパブリックドメインでも、MuseScore.com上のエングレービング(浄書データ)自体にはアップロード者独自の利用条件が付くことが多い。アプリへの同梱・配布を想定する場合は、採用前に個別にライセンス表記を確認すること。
- 著作権保護期間中の作曲家の曲(例: デュリュフレ `1986年没`、オルフ `1982年没`)は、たとえ「無料」を謳うアップロードが見つかってもこのリストには含めていない。使用しないこと。

## 次のアクション候補

1. ブラームス『ドイツ・レクイエム』とベートーヴェン第9のページを直接開き、.mxl/.mscz添付の有無と声部構成(合唱パートが個別`<part>`に分かれているか)を確認する。
2. 確認が取れたものから`content/musicxml/`配下に取り込み、既存の変換パイプライン(`scripts/musicxml/`)で処理できるか検証する。
3. 全曲を無料MusicXMLで揃えるのが難しい曲については、OMR(homr/Audiveris)でPDFから起こす方針に切り替える。
